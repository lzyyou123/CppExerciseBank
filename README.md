# C++练习题 · 分章题库

单文件、零依赖的分章刷题网页，配套本地编译判题服务。题目按徐英慧《C语言程序设计》第3版（微课版，清华大学出版社）十章体系整理。

- 含大量“读代码写结果”型选择题，答案均经真实编译运行校验
- 标注体系：常考题 / 易错题 / 难题（三色徽章），支持一键“只看重点题”
- 第 1~3 章严格只含顺序结构，不出现分支与循环
- 代码风格与课堂一致：`stdio.h` / `scanf` / `printf`，不使用 `iostream`

## 目录结构

```
web/index.html           本地完整版（含判题入口）
web/public/index.html    公网分享版（隐藏判题入口，可直接部署到静态托管）
judge/server.py          本地判题服务（http://127.0.0.1:8765，调用本机 g++）
judge/start.bat          启动判题服务
judge/打开题库（自动判题）.vbs   一键启动服务并打开页面
judge/启动题库公网分享.cmd       起静态服务 + SSH 隧道对外分享
data/ch01~ch10.json      题库数据（选择题 + 编程题 + 测试用例）
build/build5.py          构建脚本：读取 data/ 与 template.html 生成单文件网页
build/template.html      页面模板（样式、标签页、筛选逻辑）
```

## 运行方式

### 只刷选择题
直接双击 `web/index.html`，浏览器打开即可，无需任何环境。

### 需要编程题判题
1. 确认本机已安装 g++（MinGW / MSYS2 均可）
2. 双击 `judge/start.bat` 启动判题服务（默认端口 8765）
3. 双击 `judge/打开题库（自动判题）.vbs`

判题流程：浏览器把代码 POST 给本地服务 → 服务写入临时文件 → `g++ -std=c11` 编译 → 用各题的多组测试输入实跑 → 比对输出。

### 重新构建网页
```
cd build
python build5.py
```
构建脚本读取 `../data/ch01~ch10.json` 与 `template.html`，输出单文件 HTML。

## 说明

- 判题服务只监听 127.0.0.1，不对外暴露编译执行能力
- 公网分享版可用任意静态托管平台发布
